C语言

1. 字符串和字符数组 char a[5] = {'H', 'e', 'l', 'l', 'o'}; //字符数组，不是字符串 char b[6] = {'H', 'e', 'l', 'l', 'o', '\0'}; //字符数组，也是字符串 char c[] = "Hello"; //与 b 的内容和大小相同 在 C 语言中，字符串是以空字符 '\0' 结尾的字符序列，通常使用字符数组来存储。字符串中的每个字符占据一个数组元素，最后一个 '\0' 用于标识字符串的结束。 2. 数组名和&数组名 int a[5] = {10, 20, 30, 40, 50}; printf("%p\n", (void *)a); //数组首元素的地址 printf("%p\n", (void *)&a); //整个数组的地址 printf("%p\n", (void *)(a + 1)); //移动一个数组元素 printf("%p\n", (void *)(&a + 1)); //移动整个数组的大小 在 C 语言中，数组名 a 和 &a 的地址值相同，但它们的类型不同。数组名 a 在大多数表达式中会自动转换为指向首元素的指针，而 &a 表示整个数组的地址。 a：通常转换为 int * 类型，指向数组的第一个元素。 &a：类型为 int (*)[5]，表示指向整个数组的指针。 a + 1：地址增加一个数组元素的大小，即 sizeof(int)。 &a + 1：地址增加整个数组的大小，即 sizeof(a)。 3. 形式参数和实际参数 int add(int a, int b) // a、b 是形式参数 { return a + b; } int main(void) { int x = 10; int y = 20; int result = add(x, y); // x、y 是实际参数 return 0; } 形参：函数定义中的参数变量，用于接收实参传递的值。 实参：调用函数时提供的具体值或表达式。 参数传递：C 语言采用值传递，函数调用时将实参的值传递给对应的形参。 4. 全局变量和局部变量 #include <stdio.h> int a = 10; // 全局变量 void test(void) { int b = 20; // 局部变量 printf("%d\n", a); printf("%d\n", b); } int main(void) { test(); printf("%d\n", a); // 正确 // printf("%d\n", b); // 错误，超出作用域 return 0; } 在 C 语言中，全局变量是在函数外部定义的变量，而局部变量是在函数或代码块内部定义的变量。两者的主要区别在于作用域、生命周期和初始化方式。 ...
